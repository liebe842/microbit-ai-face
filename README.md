# 카메라 AI 마이크로비트 (마이크로비트 수업 슬라이드)

2026학년도 결빛 네트워크 연계 구산 「CODE_Boost」 주말 코딩 캠프 원고예요. 강사는 부내초 교사 유경윤이에요.

컴퓨터 웹캠으로 보는 AI를 Teachable Machine으로 학습시키고, Make: AI Robots로 micro:bit와 이어서 반응하게 만들어요. 지난 차시 'AI 운동 코치'(센서 AI)에 이어지는 3시간 수업이에요.

- **같이 하기 (50분):** 표정 알아보는 micro:bit (smile · sad · none)
- **스스로 하기 (70분, 짝 활동):** AI 스쿼트 코치 ★ 자세 그림 → ★★ 횟수 세기 → ★★★ 10번 축하

| 자료 | 위치 |
|---|---|
| 슬라이드 (43장) | `index.html` |
| PDF 원고 | `camera-ai.pdf` |
| MakeCode 코드 | `code/` 폴더 (JavaScript로 붙여 넣으면 블록으로 바뀌어요) |

- **조작키:** ←/→ 또는 클릭으로 넘기기 · `N` 선생님 메모 · `F` 전체 화면 · `P` 인쇄
- **슬라이드 번호로 바로 가기:** 주소 끝에 `#31`처럼 번호를 붙여요

## 구성

1. 도입 (1~8장): 지난 시간 센서 AI, 카메라 AI 알아보기, 오늘 쓸 도구, 웹캠에서 micro:bit까지
2. 같이 하기 · 표정 (9~28장): Teachable Machine 이미지 프로젝트, 클래스·데이터·학습·내보내기, 개인정보, Make: AI Robots 시작 코드·연결, 미션 체크, 문제 해결
3. 쉬는 시간 (29장)
4. 스스로 하기 · 스쿼트 (30~40장): 한 장 지도, 포즈 프로젝트, 자리 잡기, ★ 자세 그림, ★★ 횟수 세기, ★★★ 목표 축하
5. 마무리 (41~43장): 발표, 카메라 AI와 공정성·개인정보, 정리

## 준비물

웹캠이 있는 노트북(Chrome 또는 Edge), micro:bit, USB 데이터 케이블이 필요해요. AI는 컴퓨터에서 돌기 때문에 micro:bit는 USB로 계속 연결해 둬요. 스쿼트 활동에는 노트북 앞에 2~3m 공간이 필요해요.

## 수업 전에 꼭 확인할 것

- **makeairobots.com 보안 경고:** 2026년 11월 확인 기준으로 사이트 인증서가 만료(2026-11-02)되어 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나와요. 원고 21장은 [고급] → 이동으로 넘어가는 방법을 안내해요. 학교 컴퓨터·학교 망에서 미리 열어 보세요.
- **연결 단계(26장):** 모델 링크를 넣는 위치 등 Make: AI Robots의 연결 화면은 실제 micro:bit와 웹캠으로 한 번 해 보며 확인해 주세요.
- **스쿼트 횟수 세기(38장):** 사이트가 결과를 보내는 빈도에 따라 반응 속도가 달라질 수 있어요. 수업 전에 실제로 10번 세어 보세요.

## 출처

- 연결 사이트와 시작 코드는 Steamlabs의 [Make: AI Robots](https://makeairobots.com/)를 사용했어요.
- AI 학습은 Google [Teachable Machine](https://teachablemachine.withgoogle.com/)을 사용했어요.
- Teachable Machine 화면은 Teachable Machine에서, 블록 그림은 [Microsoft MakeCode](https://makecode.microbit.org/)에서 캡처했어요.
